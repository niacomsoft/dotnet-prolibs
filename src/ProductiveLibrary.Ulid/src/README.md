# README

> 生成 `Ulid` 格式的标识符
>
> Generate `ULID` Identifier.

> [!NOTE]
>
> 此类库基于 “**NUlid**”，用于生成 “`ULID`” 格式的数据标识符。此类库仅适用于 “**.NET Standard 2.0**” 及其兼容版本的框架。
>
> Such libraries are based on "[NUlid](https://www.nuget.org/packages/NUlid)" and are used to generate data identifiers in "ULID format". Such libraries are only available for "**.NET Standard 2.0**" and its compatible versions of the framework.

1. 依赖 Dependency
   1. .NET Standard 2.0
   2. [NUlid](https://www.nuget.org/packages/NUlid)
