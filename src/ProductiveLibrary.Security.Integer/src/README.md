# README

> HashId 扩展
>
> Integer Convert To HashIds

> [!NOTE]
>
> 此类库提供了基于 "**Hashids.net**" 的 Int32、Int64 哈希转换扩展。此类库主要是为了保护前端项目中可能暴露的整型值数据标识符。
>
> This type of library provides an "**Hashids.net**" based Int32 and Int64 hash conversion extension. The main purpose of such libraries is to protect integer identifiers that may be exposed in front-end projects.

1. 依赖 Dependency
   1. [Hashids.net](https://www.nuget.org/packages/Hashids.net)
